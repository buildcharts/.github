## What is BuildCharts?

BuildCharts is a Helm-inspired build pipeline generator that brings Infrastructure as Code to builds. It turns shared build logic into versioned OCI-backed platform artifacts, enables controlled rollouts with Renovate or Dependabot, and generates BuildKit-powered Docker Buildx Bake plans with strong orchestration, parallelism, and caching for local/CI execution.
